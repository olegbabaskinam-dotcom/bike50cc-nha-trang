# Регистрация сайта в Naver (корейское SEO) — runbook

Цель: чтобы `bike50cc-nha-trang.asia` индексировался в **Naver** (главный поисковик Кореи). Инструмент — **Naver Search Advisor** (네이버 서치어드바이저), это аналог Google Search Console.

**Что уже готово (проверено 07.09.2026):** корейские страницы имеют `<html lang="ko">`, hreflang (ko/en/ru), корейские title/description; `robots.txt` пускает наверовского бота **Yeti**; sitemap объявлен и содержит все 24 KR-страницы. Со стороны сайта делать ничего не нужно, кроме одного verification-тега (его деплою я).

---

## Шаг 1. Аккаунт Naver
Нужен любой аккаунт **naver.com**. Если нет — зарегистрируй (создание аккаунта и ввод паролей делаешь только ты, я к этому не подключаюсь). Международная регистрация возможна, иногда просит номер телефона.

## Шаг 2. Открыть Search Advisor и добавить сайт
1. Зайди на **https://searchadvisor.naver.com** → войди под своим Naver ID.
2. Вверху: **웹마스터 도구** (Webmaster Tools).
3. В поле «사이트 등록» вставь адрес и нажми добавить:
   ```
   https://bike50cc-nha-trang.asia/
   ```
   (регистрируем корень — hreflang сам подтянет корейские версии; отдельно KR-URL добавлять не нужно.)

## Шаг 3. Подтверждение владения (HTML meta)
1. Naver предложит способы подтверждения — выбери **«HTML 태그»** (HTML-тег).
2. Он покажет строку вида:
   ```html
   <meta name="naver-site-verification" content="XXXXXXXXXXXXXXXXXXXX" />
   ```
3. **Скопируй эту строку (или только значение content) и пришли мне** — я задеплою тег на все страницы сайта и подтвержу, когда GitHub Pages пересоберётся (1–2 мин).
4. После этого вернись в Naver и нажми **«확인»** (подтвердить). Должно стать verified.

## Шаг 4. Отдать sitemap
1. В Search Advisor: **요청 → 사이트맵 제출** (Request → Submit sitemap).
2. Вставь:
   ```
   sitemap.xml
   ```
   (полный адрес: `https://bike50cc-nha-trang.asia/sitemap.xml`)

## Шаг 5. Ускорить индексацию
1. **요청 → 웹페이지 수집** (Request → Web page collection) — отправь главную и 2–3 ключевые KR-страницы:
   - `https://bike50cc-nha-trang.asia/index-kr.html`
   - `https://bike50cc-nha-trang.asia/catalog-kr.html`
   - `https://bike50cc-nha-trang.asia/blog-kr.html`
2. В **검증 → robots.txt** и **사이트맵** можно проверить, что Naver всё видит.

---

## Что даёт и что дальше
- Naver ≠ Google: свой индекс, свой бот Yeti, свои факторы. Регистрация + sitemap = сайт начинает попадать в наверовскую выдачу.
- Naver любит корейский контент и активность. Для роста позже: писать KR-статьи в блоге (уже есть движок), по возможности упоминания/ссылки на корейских площадках, и вести аккаунт в KakaoTalk/каналах для корейцев.
- **Google Search Console** стоит завести отдельно (для остального мира) — скажи, если сделать инструкцию и по нему.
