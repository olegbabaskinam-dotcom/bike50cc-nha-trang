# Исходники листов для папки покупателя

Здесь лежит **исходник** паспортов байков. Из него собираются все 6 листов:
RU / EN / KO × красный / синий. Готовые PDF лежат на уровень выше — в папках `RU`, `EN`, `KO`.

## Зачем это нужно

Раньше были только PDF. Поменять в PDF даже одну цифру — целая история.
Теперь всё в одном файле `passport.py`: меняешь там текст или цену — запускаешь одну
команду — получаешь заново все 6 листов, одинаково и без ошибок.

## Как собрать листы (на Маке)

1. Открой приложение **Терминал** (Spotlight → напиши «Терминал»).
2. Скопируй туда эту строку целиком и нажми Enter:

```
cd ~/Documents/bike50-repo/"Папка покупателя"/_source && python3 passport.py --pdf
```

3. Готовые PDF появятся в `_source/pdf/RU`, `_source/pdf/EN`, `_source/pdf/KO`.
   Если всё устраивает — перенеси их в папки `RU`, `EN`, `KO` на уровень выше, заменив старые.

Если нужен только HTML (посмотреть в браузере, напечатать из него) — та же команда без `--pdf`:

```
cd ~/Documents/bike50-repo/"Папка покупателя"/_source && python3 passport.py
```

HTML-файлы появятся рядом со скриптом, открываются двойным щелчком.

## Что где менять в `passport.py`

| Что нужно поменять | Где искать в файле |
|---|---|
| Цена, гос-номер, номера двигателя и рамы, год | блок `BIKES` |
| Какие фото на листе (главное + 3 маленьких) | `hero` и `thumbs` в блоке `BIKES` |
| Скриншот проверки CSGT | `shot` в блоке `BIKES` (файл `proverka-csgt.png` в папке байка) |
| Любой текст на русском / английском / корейском | блок `L10N`, разделы `ru`, `en`, `ko` |
| Цвета, шрифты, отступы, размеры блоков | блок `CSS` |

## Добавить третий байк

В блоке `BIKES` скопируй целиком раздел `'blue': {...}`, назови новым ключом (например `'green'`),
подставь данные и имена файлов. В блоке `L10N` в каждом языке (`ru`, `en`, `ko`) добавь такой же
раздел с этим ключом — подзаголовок, цвет, город, тип, описание модели, интервал замены масла.
Больше ничего менять не надо, скрипт сам соберёт ещё 3 листа.

## Откуда берутся фото и скриншоты

Пути прописаны в `BIKES` и ведут в `Байки в наличии/<папка байка>/`.
Скриншот проверки по гос-номеру — файл `proverka-csgt.png` в папке каждого байка.
Если такого файла нет, на листе автоматически рисуется пунктирная заглушка —
значит, проверку ещё не сделали.

## Если что-то пошло не так

- «command not found: python3» — установи Python с python.org или через `brew install python`.
- «Chrome/Chromium не найден» — значит PDF не собрался, но HTML готов:
  открой его в браузере и напечатай через «Файл → Печать → Сохранить как PDF»,
  поля поставь «Нет», масштаб 100%.
- Картинки не видно в HTML — проверь, что папка `Байки в наличии` на месте
  и имена файлов в `BIKES` совпадают с реальными.
